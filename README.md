# DocuMind

A serverless Retrieval-Augmented Generation (RAG)
application for document question answering.

## Technology Stack

- AWS S3
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon Bedrock
- Amazon SQS
- Python 3.12
- React
- AWS SAM

## Project Structure

- backend/: Python Lambda functions
- frontend/: React application
- infrastructure/: AWS SAM templates
- scripts/: Testing and utilities

## Project Status

Development in progress.
